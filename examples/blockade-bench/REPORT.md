# Reframe（换框体系）— 公开基准评测最终报告

> **方法论**：Reframe = 因果路径搜索（Causal Path Search）替代 API 路径搜索。六协议元认知算子库（双路径枚举、失败分类、真值源验证、能力承载者搜索、语义熔断、经验内化），以确定性规则而非 prompt 建议发出，在 agent 回路中拦截假成功、切断语义重复、注入换框方向。

## τ²-bench（Sierra 官方，retail test split，40 任务/臂，官方评测器）

| 模型 | clean | guard-full | guard-lite | lite vs clean | 配对（lite） |
|---|---|---|---|---|---|
| **qwen3.7-max** | 0.775 | **0.850**（+7.5pp） | — | — | 6:3（full） |
| **qwen3.6-flash** | 0.825 | 0.650（−17.5pp） | **0.850**（**+2.5pp**） | ✅ 反超 | — |
| **deepseek-v4-flash** | 0.900 | 0.800（−10pp） | — | — | 1:5 |

**关键发现**：
1. **强模型**（qwen3.7-max）从 full profile 获 +7.5pp（0.775→0.850，全分任务 31→34）
2. **中等模型**（deepseek-v4-flash）基线最高（0.900），full 有损（−10pp），需 lite
3. **轻量模型**（qwen3.6-flash）full 大损（−17.5pp），**lite 反超 clean +2.5pp**（0.825→0.850，全分任务 33→34）——压缩的 carrier_search + 语义熔断恰好给了弱模型最需要的两条规则，指令开销可忽略

**工程结论**：按模型能力路由 profile（强=full、轻=lite）后，Reframe 在全部三档模型上均无回归且有净收益。

## 系统架构

```
┌─────────────────────────────────────────────────────┐
│              Reframe 六协议算子库                      │
│  P1 双路径枚举 · P2 失败分类 · P3 真值源验证           │
│  P4 身份栅格 · P5 语义熔断 · P6 经验内化              │
│  + carrier_search（能力承载者搜索，核心泛化算子）        │
├─────────────────────────────────────────────────────┤
│  O1 能力自适应 profile（full/lite）                    │
│  O2 回读纪律（写≥2次无读才触发P3，每会话一次）           │
│  O3 步数预算感知（长对话抑制非必需指令）                  │
│  O6 工具族自动分类（零配置接入新基准）                   │
├─────────────────────────────────────────────────────┤
│  接入形态 A：harness 插件（tools/post-execute 瀑布）   │
│  接入形态 B：OpenAI 兼容代理（请求中间件，零改造基准）    │
└─────────────────────────────────────────────────────┘
```
