# metacog

[English](README.md) | 中文

agent 元认知包：为困在被封锁写操作上的 agent 提供运行时转向。

| 包 | 角色 |
|---|---|
| [`blockade`](./blockade/) | 六协议守卫插件（双路径枚举、失败形态分类、真值源验证、身份栅格、换框触发器、经验内化） |
| [`blockade-sim`](./blockade-sim/) | 无密钥实验用的确定性封锁世界与脚本化认知策略 |

证据入口：[`examples/blockade-lab`](../../examples/blockade-lab/) — 基线对照、引导对照、消融与经验迁移，生成 `report.md`。
